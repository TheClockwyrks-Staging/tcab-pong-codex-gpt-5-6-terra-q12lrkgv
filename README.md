# Carom

Carom is a top-down paddle duel. Curve the glowing ball with paddle motion, bank it around the center obstacles, and outscore your opponent.

## Run it

Install dependencies with `npm ci`, then start development with `npm run dev`. Build the static production site with `npm run build`; it is emitted to `dist/`.

## Controls

- Left paddle: `W` / `S`
- Right paddle: arrow keys
- Select: `Enter` or `Space`
- Pause/back: `P` or `Escape`
- Mute: `M`
